# 250717 HDSD tim kiem va su dung Kho tai lieu DMS

## Hướ ng d ẫ n s ử d ụ ng

Hướ ng d ẫ n tìm ki ế m và s ử d ụ ng ' Kho tài li ệ u DMS '

## Kho tài li ệ u DMS bao g ồm hướ ng d ẫ n s ử d ụ ng v ề lu ồ ng nghi ệ p trên h ệ th ố ng DMS, chính sách c ủ a Vinfast, các l ỗ i câu h ỏi s ử d ụ ệ u DMS, n gườ i dùng truy c ập đế n Khu v ự c ; Knowledge Search.

## 1 Tìm ki ế m bài vi ế t n th ứ c b ằ ng t ừ khóa (Keyword Search)

- S ử d ụ ế m (Search bar) để nh ậ p t ừ khóa đế n n ộ i dung b ạ n mu ố n tìm.
- T ừ khóa càng ng ắ n g ọ n và chính xác thì k ế t qu ả ế m s ẽ càng nhanh và đúng ý.
- Ví d ụ : N ế u b ạ n mu ố n tìm bài vi ế t v ề ' one profile ', c ần gõ ' one profile ' thay vì câu .
- Ấ n vào bài vi ết dướ i m ụ c tìm ki ế m, n ộ i dung bài vi ế t s ẽ hi ệ n ra ở bên ph ả i.

## 2 Tìm ki ế m chính xác b ằ ng cách dùng d ấ u ngo ặ c kép ("keyword")

- Để tìm bài vi ế t có ch ứ a chính xác c ụ m t ừ khóa b ạ n nh ập, hãy đặ t t ừ khóa trong d ấ u ngo ặ c kép.
- Ví d ụ : Gõ "lu ồ " để tìm bài vi ế t ch ứa đúng cụ m t ừ này.

## 3 Thêm bài vi ế t vào My Favorite

- Khi tìm th ấ y bài vi ế t h ữ u ích, b ạ n có th ể thêm sách (My Favorite) để d ễ dàng truy c ậ p l ạ i sau này mà không c ầ n tìm ki ế m l ạ i.
- Ch ỉ c ầ n b ấ m ểu tượ ( ❤ ) ho ặ c nút Add to Favorite <!-- image -->

## Like (Thích) bài vi ế t

- B ạ n có th ể th ể hi ệ n s ự đánh giá tích cự c cho bài vi ế t b ằ b ấ m nút Like (Thích) .
- Điề u này giúp ghi nh ậ n nh ữ ng bài vi ế t h ữu ích, đồ ng th ờ i h ỗ tr ợ ngườ i khác ch ọ n l ự a n ộ i dung ch ất .

## 4 Popout để xem bài vi ết ế u b ạ n mu ố n xem bài vi ế t trong c ử a s ổ l ớn, rõ ràng hơn, bạ n có th ể b ấ m Pop out/ C ử a s ổ b ậ t lên .
- Bài vi ế t s ẽ hi ể n th ị ở c ử a s ổ riêng bi ệ t, giúp b dõi .

## 5 T ả i ệu đính kèm (nế u có)

- M ộ t s ố bài vi ế t s ẽ có file đính kèm như PDF, Word, hình ả nh …
- B ạ n có th ể t ả i ệ b ằ b ấ m vào File đính kèm ho ặc link đính kèm trong bài viế t.
